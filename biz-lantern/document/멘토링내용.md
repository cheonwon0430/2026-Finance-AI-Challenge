## 분석 자료들
 
**상장**:
1. 사업보고서 / 사업 내용, 제품/서비스, 매출 구성 확인 / 이 회사는 뭘 해서 돈을 버나?
2. 재무재표 / 최근 3~5년 숫자 비교 / 잘 벌고 있고 재무적으로 괜찮나?
3. 감사보고서 / 감사의견, 계속기업 불확실성 등 확인 / 이 숫자를 믿어도 되나?
4. 주요사항 공시 / 최근 자금조달·M&A·소송·투자 등 확인 / 회사에 큰 사건이 있었나?
5. IR 자료 / 회사가 설명하는 실적 원인과 향후 계획 확인 / 회사는 현재 상황을 어떻게 설명하나?
6. 산업보고서 / 시장 규모·성장률·산업 위험 확인 / 회사 문제가 아니라 업계 전체 문제인가?
7. 경쟁사 자료 / 매출성장률·수익성·점유율 등 비교 / 경쟁사보다 잘하고 있나?
8. 뉴스 / 최근 사건과 외부 평가 확인 / 공시 외에 무슨 일이 있었나?
9. 신용평가 자료 /. 신용등급, 차입금, 상환능력 확인 / 돈을 갚을 능력이 충분한가?
**비상장**:
1. 회사 기본정보 / 홈페이지, 법인등기, 사업자 정보 / 실제 사업, 대표, 본점,설립연도 확인
2. DART 등록 여부 확인 / DART에서 확인 가능 / 외감 비상장사면 감사보고서, 재무자료 확보 가능
3. 재무정보 / 감사보고서, 기업신용정보 DB / 매출,이익,부채,현금흐름 분석
4. 주주, 투자 이력 /. 등기, 투자기사, 회사 발표 / 누가 투자했고 자본구조가 어떤지
5. 사업.제품 / 홈페이지, 채용공고, 특허, 보도자료 / 실제로 뭘 팔고 어떻게 돈을 버나
6. 거래.고객 /. 회사 자료, 기사, 조달 납품 정보  매출 기반의 거래처 의존도 확인
7. 사업.경쟁사 / 산업보고서, 경쟁사 자료 / 시장 내 위치 비교
8. 리스크 / 신용평가, 소송.등기.뉴스 등 / 부실 자금난 법적 위험 탐색
 
### 분석 및 추론 흐름 예시
 
1. **매출 증가 vs 현금흐름 마이너스** 발생 → 의문 제기
2. **부채의 갑작스러운 증가** 확인 → "어디서 돈을 빌렸는가?" 조사
3. **전환사채(CB) 발행** 확인 → "시장에 문제가 있는가?" 의구심 확장
4. **특정 고객 의존도가 지나치게 높음** 발견 → "해당 고객이 이탈하면 어떻게 되는가?" 위험 파악
5. **결론:** 숫자가 이상하거나, 흐름이 이상하거나, 특정 고객 중심 거래일 경우 **자료조사 → 근거 기록 → 원인 분석** 과정을 필수로 거쳐야 함.
 
### 상장기업
 
- 시장 평균치(평균값)구하기가 수월하여 **비교적 분석이 쉽다(실제론 해봐야 알겠지만)**
- **정보 공개의 틀이 갖춰진 대신, 분석 보고서의 퀄리티와 정밀도를 높게 뽑아내야 함.**
- **한글과컴퓨터 분석 예시 (유사기업: 폴라리스오피스):**
    - **사업보고서 길이 분석:** 분량이 길수록 유의미한 정보가 많아 유리함 (문제를 못 찾았을 때는 분량이 긴 것을 우선 확인).
    - **재무제표:** 초보자가 보기에 이해하기 어려운 항목들이 존재할 수 있음.
    - **감사보고서:** 감사의견, **계속기업 존속불확실성** 확인.
    - **주요사항 공시:** 최근 자금 조달, M&A, 소송, 투자 등 '돈과 직결된 대형 사건' 파악 (숫자가 극단적으로 변했다면 큰 사건이 발생한 것). 공시가 굉장히 다양한데 정확하게 어떤 걸 봐야 하는지는 제목 보고 감을 잡아야함.
    - **산업 보고서:** 문서관리 프로그램 등 관련 산업 전체의 시장 동향 파악.
    - **정체성 검증 예시:** 스스로를 "AI 혁신 플랫폼 기업"이라 홍보하고 AI SaaS를 소개하지만, 실제 매출이 공공기관 구축사업(30억 수주 등) 및 PM 대량 채용에서 나온다면 실질적으로 **SI 회사도 SaaS 회사도 아닌 애매한 정체성**을 지닌 것으로 평가함.
 
### 비상장기업
 
- 정보의 정확도가 다소 떨어져도 **추론과 정보전달**만으로도 충분히 서비스적 메리트가 존재함 → 분석 리포트까지 가는게 목표긴 함.
- 정보 자체가 검색이 안되는 경우 다수.
- **업스테이지 분석 예시:**
    - 사업자등록번호 검색
    - **DART(전자공시시스템) 검색** 진행 (감사보고서라도 나오면 재무제표 확보 가능하여 훨씬 유리함).
    - 주주 및 투자 이력은 공시가 없더라도 **뉴스 검색**을 통해 파악.
- **투자 이력 및 재무 리스크 추적:**
    - 투자를 지속적으로 잘 받다가 갑자기 끊긴 기업은 이상 징후로 판단.
    - 현재 남은 자본금 규모와 매출 상승 여부 확인.
- **타깃 기업 선정 기준 (초기 데이터 구축 시):**
    1. 처음부터 **DART에 상장/공시가 이루어진 비상장 기업**을 우선 표적으로 설정.
    2. **2020년 이후 설립된 창업 기업**을 대상으로 설정.
    
    DART에서도 법인유형을 기타법인(외감대상 비상장법인 등)으로 놓고 검색할 수 있고, 비상장법인의 감사보고서도 외부감사관련 → 감사보고서에서 찾을 수 있음
    
 
### DART 공시 및 유료 데이터 처리
 
- DART 공시 조회 기반이나, 상세 유료 자료는 제외하고 진행.
- 감사보고서 등 일부 유료 조회 자료의 경우, **"유료 조회를 진행할 것인지"** 사용자에게 확인을 받는 방식을 도입할 수 있음 (**현재 단계에서는 무료 데이터만 대상으로 개발**).
 
### 서비스 성능 요구사항
 
- 사람이 보고서를 작성하는 데 보통 **20분~40분** 정도로 가정하면, **AI 모델의 추론 속도는 이보다 빨라야 함.**
- 기본적으로 추론 모델(Reasoning Model)을 적극 활용함.
 
### 필터링 및 룰베이스(Rule-based) 로 처리할만한 기준들
 
1. **정보 공개 수준에 따른 추가 가점 부여:**
    - 정보가 투명하게 모두 공개된 경우 추가 가점을 부여.
    - 리스크나 신뢰도 저하 요소가 있더라도, 정보를 숨기지 않고 공개한 것 자체를 투자/협력 시 주요 긍정 요소로 평가.
2. **즉시 제외(필터링) 대상 조건:**
    - **무반응/유령 기업:** 투자(특히 대기업)를 유치했다고 홈페이지에 명시했으나, 블로그·뉴스 등 아무런 소식이 없는 기업.
    - **지배구조/소재지 불분명:** 대표자가 자주 변경되거나 실제 주소지가 없는 기업 (법인 등기부등본 확인(700원? 유료긴 함) 또는 네이버/크롬에서 `회사명 + 투자 + 시리즈` 검색으로 검증).
    - **데이터 완전 부재:** DART, NICE, KDA 이 3개의 주요 기업 정보 DB 어디에서도 조회가 안 되는 기업은 **룰베이스로 즉시 걸러냄.**
    - **이상 매출 구조:** 매출의 대다수가 한쪽에서 발생하는 기형적인 구조.
3. **포털 검색을 통한 비상장 기업 정보 보완:**
    - `회사명 + 부채 + 연도` 검색으로 부채 흐름 확인.
    - `회사명 + 매출` 검색 후 뉴스 기사를 통한 실적 추정.
    - (단, 미공시 기업의 언론 보도 등은 거짓 정보일 가능성도 항상 염두에 둠.)
4. **미등록 기업 위험 등급 부여:**
    - DART 미등록 상태인 비상장 기업은 **"위험 등급"** 부여.(그렇게 처리하는게 나을것 같다고 하심)
    - **안내 문구:** *"등록되지 않은 사업자여서 조회가 불가능합니다. DART에 등록되어 있지 않아 신뢰도 점수가 하락하였습니다."*
    - 서비스 내에서 점수 및 위험 등급을 표시할 때, **평가 기준을 명확히 명시**해야 함.
    - 점수, 위험등급. 이런걸로 표시를 할거면 표시 할수 있어도 좋음. 단 그 기준이 어느정도 합리적이어야 한다. 그리고 사람인에서 위험도 평가 해주는데 그 기준을 밝히지 않듯이 무조건 공시할 필요는 없는듯.
 
## 현직 활용도
 
이러한 서비스들은 목적이 단순 '투자 판단'에만 국한되지 않음.
 
- **외주 및 협력사 검증:**
    - 기업 입장에서 사진/영상 추적 등 외주를 맡길 업체를 찾거나 협력사를 선정할 때, **기업명 입력 시 DART 및 네이버 검색을 통해 기업 주소, 사업자등록번호, 관련 뉴스, 부채/매출 이슈까지 끝까지 파헤쳐 주는 자동화 프로그램**으로 활용.
- **인력 배치 및 헤드헌팅(중개) 검증:**
    - 인력이 부족한 상황에서 특정 기업으로 인력을 보낼 때의 이득 계산.
    - 조건이 지나치게 좋을 때의 리스크 검증.
    - 입사 지원 시 타 기업을 추천해 주는 헤드헌터.
- **보완적 출처 활용:** DART 조회가 어려운 경우 사람인 등의 채용 포털 정보도 보완적으로 참고 가능 (필수 포함 사항은 아님, 우리는 여기까지 구현하지는 않을것임).
 
### 타깃 사용자 및 지향점(일단 공모전이랑 연결해보려 생각해본것들, 연결성은 추가로 마련해보자)
 
- B2B 기업 분석뿐만 아니라, **개인 투자자 및 청년층 자산 형성 시 참고할 수 있는 안전성·신뢰성 확보 도구**로 제공.
- 무분별한 주식 리딩방 등의 정보보다 훨씬 정확하고 객관적인 정형/비정형 데이터 분석을 지향함.
- 본 서비스는 **투자를 직접 권유하는 서비스가 아님**을 명확히 함.

## 결론
 
상장사: 공시자료 → 분석
 
비상장사: 흩어진 자료 수집 → 사실 확인 → 부족한 정보 추론 → 교차검증 → 분석
 
**상장사의 경우 이미 만들어진 서비스들도 꽤 존재하고, 공개 자료들이 많기에 심사시 높은 퀄리티를 요구한다. 추론을 매우 빠른속도로 진행하게 한다던지, 아니면 리포트의 추론 퀄리티가 높게 요구된다.**
 
**비상장사의 경우 공개된 자료가 많지 않다는 사실들을 심사위원들도 알기에 약간 퀄리티가 낮게 나와도 어느정도는 이해를 하는 편.** 
 
비상장 기업들 분석 프로그램을 만들 경우 러브콜을 보내는 기업들이 많을 수도 있다고 하심.(멘토님 의견입니다 ㅎㅎ)
 
### 비상장으로 만들거면 → DART + 기업신용정보 + 법인정보 + 투자내역 + 뉴스 + 홈페이지 + 채용공고를 AI가 자동 수집하고, 서로 모순되는 정보와 기업 리스크를 찾아 보고서를 작성하여 제공하는 서비스 가 목표가 될 것이라고 하심
 
비상장기업의 경우 DART공시 여부에 따라서 1차로 필터링을 하고, 그리고 나머지 정보들은 검색을 통해서 해결할 수 있을것 같다고 하셨는데, 그렇다면 정보를 얻는 경로를 두가지로 한정할 수 있어서 구상할때 꽤 괜찮게 구성될수 있을듯.
 
단 어떤 내용을 검색해야 기업신용정보 + 법인정보 + 투자내역 + 뉴스 + 홈페이지 + 채용공고 이런 내용이 포함된 양질의 정보를 검색할 수 있을지 프롬프트 엔지니어링이 필요.
 
RAG로 정보 가져올때 metadata처리를 잘해서 출처를 확인할 수 있도록 하는것도 중요할듯.
 
비상장기업 특성상 네이버 뉴스나 블로그는 홍보성 기사(바이럴)나 거짓 정보가 많을 수 있는데, 뉴스나 블로그 데이터를 추출할 때 "정보원(출처)의 신뢰도 가중치"를 두어야 합니다. (예: 언론사 공식 기사 > 블로그/카페글). 기사 내용과 DART 공시 데이터가 충돌할 경우 DART 데이터에 절대적 우선순위를 부여하는 로직도 추가해야 할것 같음.
 
사람인 등도 위험도 평가 기준을 명확히 밝히지 않는다고는 하지만, 사용자(특히 B2B)에게 신뢰를 얻으려면 "왜 이 위험 등급이 나왔는지" 감점 요인(Breakdown)을 제공할 수 있어야 할것 같긴 함.
