현재까지의 **팀원 로컬 실행 기준**으로 핵심 결론만 정리하면 다음과 같습니다.

| 단계 | 작업           | 필요한 결론 / 명령어                                               |
| -: | ------------ | ---------------------------------------------------------- |
|  1 | GitHub Clone | `git clone` 후 `biz-lantern` 진입                             |
|  2 | Node.js      | 설치되어 있어야 함                                                 |
|  3 | pnpm         | `corepack enable` → `pnpm --version` 확인                    |
|  4 | Frontend 의존성 | 프로젝트 root에서 `pnpm install`                                 |
|  5 | Python       | **Python 3.13 이상** 필요                                      |
|  6 | uv           | `uv --version` 확인                                          |
|  7 | Backend 의존성  | `apps/backend`에서 `uv sync`                                 |
|  8 | PostgreSQL   | Docker Desktop 실행 후 `docker compose up -d`                 |
|  9 | 환경변수         | Backend의 DB 접속 설정과 Docker PostgreSQL 설정 일치 여부 확인           |
| 10 | DB 테이블 생성    | 현재 Alembic을 사용하지 않으므로 `Base.metadata.create_all()` 기반으로 생성 |
| 11 | DB 확인        | `SELECT tablename FROM pg_tables ...`로 테이블 확인              |
| 12 | Backend 실행   | `cd apps/backend` → `uv run fastapi dev`                   |
| 13 | Frontend 실행  | `pnpm --filter frontend dev`                               |
| 14 | 최종 구조        | **PostgreSQL(Docker) + FastAPI(uv) + Vite/pnpm** 구조로 로컬 실행 |

### 팀원이 최초 한 번만 하는 작업

```text
Git clone
   ↓
Node / pnpm 확인
   ↓
Python 3.13 / uv 확인
   ↓
pnpm install
   ↓
uv sync
   ↓
docker compose up -d
   ↓
DB 테이블 생성
```

### 이후 개발할 때

```text
Docker PostgreSQL 실행
        ↓
Backend 실행
        ↓
Frontend 실행
```

즉, **팀원에게 필요한 핵심 패키지 설치는 `pnpm install`과 `uv sync`가 담당하고, PostgreSQL은 Docker가 담당**한다고 이해하면 됩니다.

그리고 현재 프로젝트에서는 **Alembic은 사용하지 않는 상태**이므로 팀원 실행 절차에도 Alembic 명령어는 들어가지 않습니다.
